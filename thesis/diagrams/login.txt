sequenceDiagram
    autonumber
    actor U as User
    participant UI as Login UI<br/>(React SPA)
    participant AC as AuthController<br/>(Laravel API)
    participant DB as User model<br/>+ database

    U->>UI: Enter email and password
    UI->>AC: POST /api/auth/login

    Note over UI,AC: A.1 Missing or malformed input<br/>is refused by the form before it is sent

    AC->>DB: Find the account by email
    DB-->>AC: user row, or none
    AC->>DB: Verify the password against its hash
    DB-->>AC: hash, or no match

    alt A.2 Unknown account, A.3 locked, A.4 inactive
        AC-->>UI: 422 refused (one message for all three)
        UI-->>U: Show the error, stay on the form
    else Credentials correct and account usable
        AC->>AC: Reset the failed attempt counter
        AC->>AC: Record the sign-in in the audit log
        AC->>DB: Create the Sanctum token
        DB-->>AC: token, user, home route
        AC-->>UI: 200 OK
        UI-->>U: Redirect to the role dashboard
    end

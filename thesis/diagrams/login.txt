sequenceDiagram
    autonumber
    actor User
    boundary LoginUI as Login screen<br/>(React SPA)
    control AuthController as AuthController<br/>(Laravel API)
    control LoginRequest as LoginRequest<br/>(validation)
    database DB as PostgreSQL
    control UserModel as User<br/>(model)
    control Audit as AuditLogger

    User->>LoginUI: Enter email and password
    LoginUI->>LoginUI: Validate the form (required, email, max 255)
    LoginUI->>AuthController: POST /api/auth/login
    AuthController->>LoginRequest: Validate and normalise the request
    LoginRequest-->>AuthController: email lower-cased and trimmed

    AuthController->>DB: SELECT the account by email
    DB-->>AuthController: the user row, or null

    alt A.1 The account does not exist
        AuthController->>Audit: log LoginFailed (unknown account)
        AuthController-->>LoginUI: 422 "These credentials do not match"
    else The account is locked
        AuthController->>UserModel: isLocked()
        UserModel-->>AuthController: locked until a time still in the future
        AuthController-->>LoginUI: 422 "temporarily locked until ..."
    else A.2 The password is wrong
        AuthController->>UserModel: Hash::check(password, hash)
        UserModel-->>AuthController: no match
        AuthController->>UserModel: registerFailedLogin()
        AuthController->>Audit: log LoginFailed (wrong password, maybe now locked)
        AuthController-->>LoginUI: 422 "These credentials do not match"
    else A.3 The account is suspended or inactive
        AuthController->>UserModel: isActive()
        UserModel-->>AuthController: status is not "active"
        AuthController-->>LoginUI: 422 naming the reason
    else Credentials correct and the account is active
        opt The client asks for a clean session
            AuthController->>DB: DELETE every token this user holds
        end
        AuthController->>DB: INSERT a Sanctum personal access token
        DB-->>AuthController: the plain-text token
        AuthController->>DB: UPDATE last_login_at, last_login_ip, reset failures
        AuthController->>Audit: log Login
        AuthController-->>LoginUI: 200 OK (token, user, home_route)
    end

    LoginUI->>LoginUI: Store the token, set the signed-in user
    LoginUI-->>User: Redirect to the role dashboard

    Note over LoginUI,DB: Every guarded request afterwards sends<br/>Authorization: Bearer, which Sanctum resolves<br/>to the user before the route runs.
